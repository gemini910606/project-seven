In development · friends only

Five on five.
Plant it or defuse it.

One map, one rifle, one life a round. Bots fill the empty slots, so it works whether three of you are online or all ten.

Download for Windows

No installer, no account. Unzip and run.

How to play together

  1. Everyone downloads the same build. Version mismatches will not connect.
  2. One person clicks Host and gets a six-character join code.
  3. That code goes in Discord. Everyone else pastes it into Join.
  4. Bots top both teams up to five. First to seven rounds wins; sides swap at six.

Connections go through Unity Relay, so nobody forwards a port and nobody sees anyone else's IP address. The host's machine runs the match, which means the host has no ping — if that starts to matter, take turns hosting.
